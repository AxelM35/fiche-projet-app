# Captures d'écran du README

Ce dossier accueille les captures illustrant la section « Aperçu » du
[README](../../README.md). Les images ne peuvent pas être générées
automatiquement : toutes les pages de l'application sont derrière
l'authentification Google, et ajouter un contournement de connexion pour les
produire dégraderait la sécurité.

Elles sont donc à réaliser depuis une instance en fonctionnement, avec des
données de démonstration (aucune donnée réelle d'élève ou de famille).

Cadrages attendus, aux noms de fichiers repris dans le README :

| Fichier | Page | Ce qu'elle doit montrer |
|---|---|---|
| `dashboard.png` | `/dashboard` | Le Kanban complet, avec au moins un dossier dans plusieurs colonnes |
| `fiche-projet.png` | `/projets/{id}` | Une fiche en consultation, cartes thématiques et stepper visibles |
| `admin.png` | `/admin/statistiques` | Le tableau de bord administrateur |

Format conseillé : PNG, largeur 1400 à 1600 px, navigateur en pleine largeur.

Une fois les fichiers déposés ici, décommenter le bloc d'images de la section
« Aperçu » du README.
